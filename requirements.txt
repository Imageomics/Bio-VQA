# ----------------------------------------------------------------------------
#  3. Inference — READ THIS
# ----------------------------------------------------------------------------
#  The 18 evaluated models do NOT share a transformers version. Installing one
#  pin globally will break at least one family. Each SLURM array task therefore
#  builds a disposable virtual environment in node-local $TMPDIR and installs
#  the version that model needs; the environment is removed by a trap on exit.
#
#      Gemma-4                    transformers @ git HEAD
#      Qwen3-VL (dense + MoE)     transformers >= current release
#      all other 16 models        transformers == 5.5.0
#
#  The pin below is the majority case and is what a single-model reproduction
#  should start from. Do not assume it covers Gemma-4 or Qwen3-VL.
#
torch>=2.6                   # Gemma-3 raises "Using or_mask_function ... require torch>=2.6"
torchvision>=0.21
transformers==4.57.1         # majority pin — see the note above
accelerate>=0.34
sentencepiece>=0.2.0         # LLaVA-NeXT Vicuna: "Cannot instantiate this tokenizer from a slow version"
protobuf>=4.25               # the follow-on ImportError from the same tokenizer path
einops>=0.8.0                # InternVL remote code imports rearrange at module load
